kitty Manual

for Tuatara 0.90.25 and later, every chapter on one page

This manual is written with modal editing on, first and foremost. Where a command also has a key that works with modal editing off, it is given as well, as the non-modal key.

What kitty is

A package that opens windows of the kitty terminal from Tuatara, reads their text into a buffer and types into them.

kitty is a terminal drawn by the graphics card, with ligatures and pictures. This package opens its windows from the editor. A window here belongs to a kitty that Tuatara starts itself, never your own kitty. The editor steers it over a socket of its own, and only over that socket.

It is a package, not part of the editor. kitty itself is by Kovid Goyal. The package drives it by its remote control.

1.1 How it fits together

Tuatara starts a kitty with a socket of its own in your runtime directory. Where you have none, the socket is in a directory of Tuatara's cache that only you may enter. Tuatara sends its commands to that socket with kitten, kitty's own command line tool, which has been part of kitty since 0.28.

Three commands do the work:

  • M-x kitty opens a window;
  • M-x kitty-text brings a window's text into a buffer;
  • M-x kitty-input types a line or the selection into a window.

1.2 What this manual covers

  • Chapter 2 is the use of the three commands.
  • Chapter 3 is about running Tuatara itself in a kitty of its own, and how to set the looks of the windows.
  • Chapter 4 says what keeps a program in a window from steering kitty, and lists the setting and the limits.
  • Chapter 5 lists every command and setting.

Opening, reading and typing into a window

Open a kitty window, read its text, and type into it.

2.1 Opening a window

M-x kitty opens a kitty window in the current buffer's directory, running your shell. How it opens depends on where Tuatara runs:

  • when Tuatara runs in a kitty of its own (chapter 3), the window opens beside the editor's, as a vertical split;
  • when a kitty of Tuatara's is already open, the window is a new window of that kitty;
  • otherwise Tuatara starts a kitty with its first window in the directory, and waits for it to answer, at most 5 seconds.

When there is no kitty or no kitten program, the command says which one is missing and how to install it.

ModalNon-modalCommandWhat it does
noneM-x kittykittyOpen a kitty window in the current buffer's directory: a window of a kitty the editor starts itself, with your shell (beside the editor's window when the editor runs in such a kitty, started with kitty/tuatara-kitty).

2.2 Reading a window

M-x kitty-text brings all the text of a kitty window, the scrollback too, into a buffer called *kitty: TITLE*, with its colours. You can move through it, select, search and copy as in any text. Point starts at the end, where the window's last line is. Press r there to read the window again.

If the window has closed since, the buffer says so.

2.3 Typing into a window

M-x kitty-input types the selection into a window. Without a selection, it types the line point is on, and a return, so that the shell runs it.

The text is sent as a paste (bracketed paste, where the program in the window asks for it), so that the lines of a selection are not run one by one. A line is followed by a return of its own.

2.4 Several windows

With several windows open, kitty-text and kitty-input ask which one. The window used last is offered first, and each is listed with its title and its directory. Tuatara's own window, when the editor runs in a kitty, is left out of the list. With only one window, it is used without asking.

If no window of Tuatara's is open, the two commands say that, and that M-x kitty opens one.

Tuatara in a kitty of its own, and its looks

Run the editor itself in a kitty, and set how the windows look.

3.1 The launcher

The package has a program, tuatara-kitty, in its directory:

./tuatara-kitty [--program KITTY] [FILE...]

It runs Tuatara in a kitty of its own, editing the files given, and returns at once. The kitty draws the editor with its own drawing, ligatures and pictures. M-x kitty there opens windows beside the editor's. The editor it runs is the program named by $TUATARA, else tuatara on the PATH. --program names the kitty program to use, when it is not kitty on the PATH.

The socket is in your runtime directory, else in a new directory that only you may enter.

The launcher has two more forms, which M-x kitty and the tests use:

  • --hidden starts the kitty unseen;
  • --shell DIRECTORY SOCKET starts your shell in a kitty in that directory, listening on that socket.

3.2 Its looks

A kitty of Tuatara's reads your own kitty.conf first, then ~/.config/tuatara/kitty.conf over it. A kitty.conf in the directory named by XDG_CONFIG_HOME is used in place of ~/.config when that is set.

The launcher makes ~/.config/tuatara/kitty.conf the first time, with examples only, each commented out. Any kitty setting can be put there. It applies to the windows Tuatara opens, and not to your own kitty:

# font_size 12
# background_opacity 0.95
# remember_window_size no
# initial_window_width 100c

Remote control is not set in either file. Tuatara sets it on kitty's command line, and nothing in a configuration file can undo it (chapter 4).

Safety, settings and limits

What keeps a window from steering kitty, the one setting, and what the package does not do.

4.1 Safety

kitty is told what to do over a socket. Tuatara gives remote control over that socket alone (allow_remote_control socket-only), on kitty's command line. No configuration file can undo that. A program run in the window, or a file shown in it, cannot steer kitty over the terminal.

Tuatara counts a socket as its own only when it is named tuatara-kitty- and something, is a socket and not a link, and is in your runtime directory or in the kitty directory of Tuatara's cache. Nobody else can put one there.

A window runs only what you type there. A program you run in it runs as you, and like any such program it may reach the socket. What a window only shows, such as a file's escape sequences, cannot.

kitty-input refuses text it cannot type as shown. A selection or a line with a control character in it, other than a tab or a newline, is not sent. That covers a carriage return, escape and delete, and the codes from 128 to 159. Such a character could make the shell run something other than the text you see.

4.2 The setting

Set it in the package's :config in your init file, after the package is loaded:

(load-package "kitty"
              :source "https://github.com/Tuatara-Editor/tuatara-kitty"
              :config
              (setf *kitty-program* "~/.local/kitty.app/bin/kitty"))
SettingDefaultValuesWhat it changes
*kitty-program*"kitty"textThe kitty program M-x kitty opens windows of.

The editor has a setting of its own with kitty in its name, *kitty-keyboard*. It says whether Tuatara's terminal frontend reads keys by kitty's keyboard protocol, and is for the editor running in any terminal. It does not need this package and is described in Tuatara's manual.

4.3 Limits

  • A request to kitty is given up after 5 seconds. While Tuatara waits, it keeps reading keys, and C-g gives up at once.
  • Only windows of a kitty that Tuatara started are used, never those of your own kitty.
  • kitten must be there, from kitty 0.28 or later.

Every command and setting

Each command and setting of kitty, to look one up by name.

The tables are made from the program each time this manual is made, so they never list a command or setting that kitty does not have. The first table has four columns. The first two are keys: the modal keys, which work only with modal editing on, and the non-modal keys, which work with it off too. A command with no key says M-x and its name in the second column, because you can only run it by its name. The third column is the name of the command and the fourth says what it does.

To run a command by its name, press M-x, type a few letters of the name and press RET. To find a command from within the editor, press C-h f. To find the command that a key runs, press C-h k and then the key. The editor's own settings and commands are in chapters 21 and 22 of its manual.
